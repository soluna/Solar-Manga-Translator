# InkStage 旧版功能对齐收口

目标：新版能够完成旧版已经向用户提供的工作。保留新版结构，只补缺口和修复行为；不扩展产品范围。

## 实施分工

| 批次 | Luna Max 负责范围 | 主 agent 验收重点 |
| --- | --- | --- |
| 审校 | 对照旧版可见控件，补齐区域编辑、排版、复制样式、翻译与画布操作中的实际缺口 | 对同一区域操作后保存、重载、撤销重做；多选与当前页范围准确 |
| 配置 | 设置、首次启动、字体、诊断与术语表的已有操作 | 实际请求与返回字段一致，设置持久化，密钥保留/替换/主动清除各自正确 |
| 工作流 | 导入、项目/历史/快照、任务、导出和修图 | 从导入走到可导出，失败与取消状态真实，历史恢复及空页处理可继续 |
| 验收 | 新版自身的操作回归，不以旧版 E2E 代替 | 合成素材、临时数据目录，真实页面与后端联动；记录模型替身边界 |

先由每组列出有旧版依据的缺口，主 agent 确认范围后直接交由 Luna Max 实现。仅保留影响工作完成的必要设计细节。

取舍：保留当前术语表的候选预览→采纳→保存，原有人工维护、预览应用和证据跳转均有入口。旧版 `font_style_mode` 固定为自动映射，不因此添加模式选择；自动首次引导保留旧版桌面运行条件，不抢走网页审校深链接。首次选择哪个框、区域导航首尾是否循环属于交互偏好，不按缺失功能扩展改动。

## 不要犯的错误

- 不重新设计整套界面，也不为追求按钮数量相同复制旧版未开放的残留代码。
- 不把端点出现、构建通过、Mock 成功或旧版 E2E 当作新版操作验收。
- 不删除已有用户能力来缩小验收范围；替代入口必须同样能完成原来的动作。
- 不绕开 Page Document、页面版本、任务身份和页面产物有效性。
- 不让异步操作覆盖新编辑，不在失败后清空草稿，不因重连重复启动处理。
- 不把在线服务描述成本地处理，不把浏览器预览当成最终嵌字效果。
- 不操作真实书稿与用户输出，不修改嵌套上游仓库的既有工作。
